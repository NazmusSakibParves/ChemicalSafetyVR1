# Scenario 19 audio credits

- `Assets/Art/Audio/Sc19/Cough_0..1.wav`: two real coughs of a man, cut from the Wikimedia Commons recording `File:Man coughing.ogg`
  (https://commons.wikimedia.org/wiki/File:Man_coughing.ogg, **Public domain**, artist "stilgar", segments 0.05-1.32 s and 3.85-4.70 s),
  only faded and normalised, no pitch change. Downloaded 2026-11-14 with the user's OK. The film has two coughs (client, 2026-11-14).
  (The first try, `Cough 1.ogg` / `Cough 2.ogg` by "ezwa", was dropped: the user found it not realistic.) To use a studio recording instead,
  replace `Cough_0.wav` and `Cough_1.wav`, nothing else.
- Everything else (`Plant_Loop`, `Blower_Loop`, `Gasp`, `Thud`, `Beep`, `Clank`, `Pen`) is generated by `Tools/generate_sc19_audio.py`.
